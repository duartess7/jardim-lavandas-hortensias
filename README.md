# Jardim de lavandas e hortênsias

Uma experiência botânica noturna feita com HTML, CSS e JavaScript puros. Lavandas e hortênsias florescem em sequência, com estrelas, vaga-lumes e movimento suave.

## Abrir localmente

Abra `index.html` em um navegador moderno. O projeto não possui dependências.

## Publicação

O site é compatível com GitHub Pages e pode ser publicado diretamente a partir da branch `main`.
